# Experiment execution

Always ask the user before running notebook cells or experiments. An explicit
request to run cells/experiments authorizes that run only. Editing notebooks,
static validation, and downloading requested datasets do not authorize later runs.

# Scope changes

Before making changes beyond the user's explicitly requested scope, explain
what will change and why, and obtain the user's approval. In particular, do not
silently alter experimental methods, feature extraction, perturbation protocols,
labels, splits, model settings, or evaluation procedures while carrying out
another requested change. An approval to run does not authorize additional
methodological changes that have not been disclosed.
